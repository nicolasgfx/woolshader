--- Object
Wool swatch on a needle (12 cm)
Example scene: imported with a fixed size and mesh selection.
Made from "Wool swatch on a needle" by Nicolas Menzel, CC BY-NC 4.0.
--- Components

Unticked components keep their mesh and textures.
--- What to make
[ Knit ] [ Fur ]
[ Open mesh (OBJ, PLY) ... ]
Or drop an OBJ or PLY file anywhere in the window. Limits: 200 MB of mesh data (textures not counted), 200 components, 2 million triangles.
--- Examples
[ Wool swatch on a needle (12 cm) ]

--- Method
Knitting follows each flattened surface piece (UV chart) of the mesh with a regular lattice of stitches. Each chart's rows continue a few stitches past its border onto its neighbours, so the seams are covered by overlapping yarn (Seams: Overlapped); the seams are not sewn and the stitch count does not shape the fabric. Every import and example is knitted this way except the teddy: it is knitted as spiral pieces (one closed spiral per body part, shaped by increases and decreases). This is the project's own method, not Stitch Mesh / Stitch Meshing.
An opened mesh is first rebuilt as one closed surface at stitch scale, with few wide charts and its base colours baked onto them, so that any model can be knitted. Components left unticked stay as the file has them.

Meshes, optional fibres, ply maps and report.

--- Method
Knitting follows each flattened surface piece (UV chart) of the mesh with a regular lattice of stitches. Each chart's rows continue a few stitches past its border onto its neighbours, so the seams are covered by overlapping yarn (Seams: Overlapped); the seams are not sewn and the stitch count does not shape the fabric. Every import and example is knitted this way except the teddy: it is knitted as spiral pieces (one closed spiral per body part, shaped by increases and decreases). This is the project's own method, not Stitch Mesh / Stitch Meshing.
An opened mesh is first rebuilt as one closed surface at stitch scale, with few wide charts and its base colours baked onto them, so that any model can be knitted. Components left unticked stay as the file has them.

--- File format
{ Photon Path Tracer package }
The mesh with its fur, and report.json.
> What the package holds
    scene.json with materials, a camera, a grey ground plane and a uniform sky; yarn tubes and an import's unknitted parts as PLY meshes (with their base colour texture); fibres as .pptstrands; ply shading maps (normal, height); report.json with the settings and every part's verdict.
    With knitting skipped: the mesh, with its base colour texture, instead of the yarn tubes.
--- Contents
The mesh and the fur grown in the Fur step.
The Fur workflow knits nothing: no yarn tubes or ply maps are written.
